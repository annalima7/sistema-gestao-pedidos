# Sistema de Gestão de Pedidos (Order Management API)

Este projeto é uma API RESTful para gestão de pedidos, clientes e produtos. Ele foi desenvolvido para demonstrar conhecimentos em **Engenharia de Software**, arquitetura de banco de dados e qualidade de código, utilizando práticas de TDD e BDD.

## 📋 Escopo e Regras de Negócio

O sistema permite o cadastro de clientes e produtos, além da realização de pedidos que podem conter múltiplos itens. A API calcula automaticamente o subtotal de cada item e o valor total do pedido.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 21+
- **Framework:** Spring Boot
- **Banco de Dados:** PostgreSQL
- **Testes:** JUnit, Mockito e Cucumber (TDD e BDD)
- **Documentação e Design:** UML (diagramas de classes e casos de uso)

## 📁 Estrutura do Projeto

- `/docs`: Contém os diagramas UML e a documentação de requisitos.
- `/database`: Contém os scripts SQL (DDL e DML) para criação e população do banco de dados.
- `/src` *(em breve)*: Contém o código-fonte da aplicação Java.
